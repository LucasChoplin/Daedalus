Merci de vouloir jouer à Daedalus !

Pour lancer le jeu : 
-Sous Linux lancer le fichier ./bin/start
-Sous Windows lancer le fichier ./bin/DaedalusWindows 
Lancer le jeu depuis un environnement avec les dll avec un terminal ou déplacer l'exécutable à la racine du projet 

Pour fonctionner le jeu utilise les libraries SDL2 et les images et a donc besoin des dépendances suivantes : 
-SDL2.dll
-SDL2_image.dll
-SDL2_mixer.dll
-SDL2_ttf.dll
-du dossier Img et assets ainsi que toutes leurs images

(attention changer l'emplacement ou renommer les dossiers empêchera le jeu de fonctionner normalement)
